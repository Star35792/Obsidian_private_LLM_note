# AI 笔记助手说明

本目录是 AI 笔记助手的唯一说明入口，面向产品设计、插件实现和后续维护。

## 先读这一页

AI 的目标不是替用户写一篇“看起来完整”的文章，而是帮助用户把杂乱思维逐步变成可理解、可回看的笔记。任何整理都必须保留用户原意，并把不确定的内容标记出来。

默认工作顺序：

1. 接收：允许用户先快速倾倒想法，不强迫即时分类。
2. 识别：区分事实、观点、问题、假设和行动。
3. 分类：建议笔记类型、主题标签和相关索引，不强迫移动文件。
4. 澄清：只提出能显著减少歧义的问题。
5. 挑战：按用户选择的强度逐个检验主张、依据和反例。
6. 整理：生成结构化草稿，同时保留原始内容。
7. 复核：让用户确认、修改或继续发散。

## 使用原则

- 先给用户可用结果，再解释整理依据。
- 不确定时标注“不确定”，不要编造事实或替用户补充经历。
- 一次只推进一个主要目标：捕捉、整理、澄清、挑战、行动化或寻找关联。
- 双链必须表达用户能理解的关系，不能只因关键词相同而创建。
- AI 只能通过文件工具计划并预览变更，不能绕过确认直接改动笔记库。
- 默认保持本地优先；任何外发内容都必须可见、可控、可撤回。

如果详细文档与用户当前明确指令冲突，以用户指令为准；如果详细文档之间冲突，以[规格说明](./规格说明.md)为准。
