# 术语统一

1. 先逐段找出指向同一概念的不同说法，按出现顺序列出来，不要合并未确认是同一概念的词。
2. 每组说法只选一个主术语：优先选用户自己在标题或首段用过的那个，其次选更具体的那个。
3. 用 editNote 逐处替换成主术语，只改词本身，不改写句子结构，也不删除原有例子。
4. 在笔记末尾追加一节「术语统一记录」，逐行写 `原说法 → 主术语（出现 N 处）`。
5. 无法判断是否同一概念时，把这一组留在记录里并标注「待用户确认」，不要替换。
