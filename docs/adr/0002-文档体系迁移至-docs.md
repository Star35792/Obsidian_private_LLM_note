# 文档体系从 ai/ 迁移至 docs/

仓库文档原集中于 `ai/` 目录（承担 README、规格、ADR 三种角色）。现决定启用标准布局：根目录 `CONTEXT.md` 作术语表，`docs/adr/` 存架构决策；后续工程逐步把 `ai/` 下的规格、设计、协议文档迁入 `docs/`，全部迁完后删除 `ai/` 目录。

迁移**渐进进行**，不一次性搬移：每次工程改动触及某份文档时顺带迁移。迁移期间原有冲突规则维持不变（用户指令 > 规格说明 > 其他文档），新旧位置并存时以 `docs/` 为准。

## Consequences

- 新文档一律写入 `docs/` 或根 `CONTEXT.md`，不再往 `ai/` 添加。
- 引用 `ai/` 路径的代码、脚本、文档在迁移到对应文件时一并更新。
