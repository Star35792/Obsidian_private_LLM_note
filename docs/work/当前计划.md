## TASK-20260821-01：变更确认展示真实行级 diff

- 状态：`done`
- 目标：确认写回前，用户看到的是带上下文的新增/删除行差异，而不是整篇建议正文。
- 范围内：新增 `src/changes/text-diff.ts` 和 `src/ui/diff-view.ts`；改造侧栏待确认卡片与整理预览弹窗；`styles.css`；`tests/text-diff.test.ts`。
- 范围外：不做逐个 hunk 接受/拒绝、不做字符级行内 diff、不做编辑器选区替换、不动 LinkContext 与双链。
- 验收：相同内容显示“没有变化”；单行修改只显示该行及上下文并给出 `@@` 位置；追加型变更只显示新增块；远距离两处变更产生两个 hunk；超大差异不卡死且标注截断；测试、build、lint 和 `git diff --check` 通过。
- 假设：diff 只用于展示，写回仍以 `ChangePlan` 的 `TextChange` 为准；展示层按 `\r?\n` 归一化行尾不影响写回内容。
- 风险：整篇替换类变更的 LCS 计算量随行数增长，需要公共前后缀裁剪和规模上限兜底，避免 UI 卡死。
- 依赖：现有 `ChangePreview`（含 `originalContent` 与 `proposedContent`）、`AssistantView.showPendingChangePlan`、`ChangePreviewModal`。
- 计划：先写 diff 单元测试与算法 → 抽出共享渲染 seam → 接入侧栏卡片和预览弹窗 → 补样式 → 运行验证并更新记录。
