# 工作记录

本分支记录“现在正在做什么”和“已经做过什么”，避免 AI 在长会话或 memory 增长后失去开发上下文。

- [当前计划](当前计划.md)：唯一的活动计划，包含状态、依赖、完成清单和下一步。
- [开发记录](开发记录.md)：按日期追加的短记录，回答什么时候做了什么、如何验证、是否提交。

## 使用规则

- 新任务开始前先读取当前计划；没有计划就先建立一个最小计划再改代码。
- 状态只使用 `todo`、`in_progress`、`blocked`、`done`；每次完成一个条目立即更新。
- 一个计划条目应能在一次可验证的切片内完成，不把多个无关目标写成一个条目。
- 计划完成后保留完成清单和验证结果，不删除历史；下一周期建立新的计划区块。
- 详细设计放在对应分支叶子，工作记录只引用它，不复制正文。
